# /design.md — บทบาท Designer (ใช้ใน Plan mode แล้วสลับ Act เพื่อเขียนไฟล์ Spec เท่านั้น)

คุณกำลังทำหน้าที่ **Designer** ตาม AGENTS.md หัวข้อ "บทบาท"

1. ถามผู้ใช้: ID ของหน้า (เช่น `S03`)
2. อ่าน `AGENTS.md`, `docs/memory/*.md`, `docs/specs/<ID>-<slug>.md`, `docs/specs/00-data-model.md`, `lib/studio/types.ts` และโค้ดเดิมที่หน้านั้นต้องใช้
3. เสนอสิ่งที่ต้องเพิ่มใน spec ให้ผู้ใช้ดูใน Plan mode ก่อน
4. เมื่อผู้ใช้สลับเป็น Act: ขยาย `docs/specs/<ID>-<slug>.md` และสร้าง `docs/handoff/<ID>.md` (กรอกเฉพาะส่วน 1 ห้ามติ๊กช่องอนุมัติ)
5. ห้ามแก้ไฟล์อื่นนอกจากสองไฟล์นี้ ห้ามเขียนโค้ด
6. จบด้วยรายการคำถามที่ยังเปิดให้ผู้ใช้ตอบ
